## 4. Top 5 "adopt now" recommendations
1. **`mineflayer@4.39.0`** — Java-agent parity (worklog admits Java bot missing). API: `mineflayer.createBot({host:'127.0.0.1', port:25565, username:'CIVITAS_AGENT', auth:'offline'})`; `bot.chat`, `bot.on('message')`, `bot.blockAt`, `bot.dig/placeBlock`. Requires node ≥22 (we have v24). Use the same runtime-only dynamic-import trick already used for bedrock-protocol. **Effort M** — highest value: both worlds get a body.
2. **`@modelcontextprotocol/server@2.1.0` + `mcp-handler@2.2.0`** — official MCP server API + Vercel's Next.js adapter. API: `new McpServer({name:'civitas-os', version:'1.1.0'})`, `server.registerTool('census', {inputSchema:{...zod}}, fn)`; in route.ts: `const handler = createMcpHandler(server); export { handler as GET, handler as POST, handler as DELETE }`. Keeps stdio script (`StdioServerTransport`) as the app-down fallback. **Effort M** (S if only /api/mcp migrates).
3. **`rcon-client@4.2.5`** — real Java console: `const rcon = await Rcon.connect({host, port:25575, password})`, `rcon.send('tp ...')`. Replaces FIFO-only control for `local-java`, enables reliable directive execution + healthcheck (server must respond to RCON, not just ping). Enable `enable-rcon=true` in Purpur properties. **Effort S**.
4. **Voyager skill-library pattern + Letta memory pattern (no new deps)** — (a) store each verified directive/tool script as retrievable skill keyed by goal tags (`CivArtifact` + recall in memory.ts); (b) add kernel-audited `memory.edit_core` + nightly consolidation step in `selfLifeTick`. **Effort M**, zero new packages.
5. **`pm2@7.0.4`** (optional) — programmatic supervision: `pm2.connect()`, `pm2.start({script:'scripts/civitas_selflife_tick.ts', interpreter:'bun', max_restarts:20, cron_restart:'0 */6 * * *'})`, `pm2.launchBus()` → stream restarts/logs into CivConsoleLog. Replaces parts of `civitas_daemon.sh` while keeping FIFO shells for server processes. **Effort M**; defer if daemon.sh remains stable.

- Co-Voyager (cooperative task decomposition fork) — revisit for multi-villager task splits.
